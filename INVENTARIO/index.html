🔑 Conexión Segura con GitHub (Token PAT)
¿Cómo generar tu Token en 1 minuto?
  1. Ingresa a github.com con la cuenta epspatrimonio.
  2. Clic en tu foto (arriba derecha) → Settings → abajo izquierda Developer settings.
  3. Personal access tokens → Fine-grained tokens → Generate new token.
  4. En Repository access elige Only select repositories → marca ACTIVOS-FIJOS.
  5. Abre Permissions → Repository permissions → en Contents selecciona Read and write.
  6. Clic en Generate token, copia el código (github_pat_...) y pégalo abajo.
